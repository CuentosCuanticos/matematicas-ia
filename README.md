# Matemáticas de la Inteligencia Artificial

Curso de **Cuentos Cuánticos** dedicado a construir, desde sus fundamentos matemáticos, modelos de aprendizaje automático desde el perceptrón hasta un pequeño modelo de lenguaje.

## Entorno oficial

- Python
- Jupyter Notebook
- Google Colab
- NumPy y Matplotlib en las primeras sesiones
- PyTorch a partir de la transición prevista en el curso

## Flujo de trabajo del alumno

**Campus → GitHub → Abrir en Colab → ejecutar y modificar → guardar copia personal**

## Cuadernos

- `00_preparacion/` — preparación del entorno.
- [`01_perceptron/laboratorio.ipynb`](01_perceptron/laboratorio.ipynb) — Sesión 1: perceptrón desde cero.
